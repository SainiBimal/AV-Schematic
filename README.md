# JP Boomerung Complex, Noida — AV System Schematic

A professional Audio-Visual (AV) system schematic documenting equipment connectivity, video and audio signal flow, network infrastructure, and control integration for the JP Boomerung Complex, Noida project.

## Overview

This project documents the AV system architecture and connectivity for an integrated conference and video conferencing environment. The schematic identifies major AV equipment, source devices, display systems, audio conferencing components, control interfaces, and network connections.

The documentation is intended to support AV installation, commissioning, troubleshooting, maintenance, and technical reference.

## Features

- 📐 AV system schematic and equipment connectivity
- 📺 HDMI video signal routing and display connectivity
- 🎥 PTZ camera and video conferencing integration
- 🔀 ATEN 8×8 HDMI matrix switcher
- 🎛️ Aurora RXC-3 control processor
- 🎤 TOA digital conference system and delegate microphones
- 🔊 TOA mixer amplifier and ceiling speaker connectivity
- 💻 Script laptop and Zoom laptop integration
- 🔌 Network connectivity using a Netgear 16-port PoE switch
- 🔄 CYP HDMI multiviewer and HDMI-to-USB capture interface
- 📱 iPad controller integration
- 🗂️ Technical documentation for installation and support

## Cable Types

The schematic identifies the following cable types:

- **CAT-6:** Network connectivity
- **HDMI:** Video signal connectivity
- **USB:** USB connectivity between compatible devices
- **Speaker Cable:** Audio output connectivity to the ceiling speaker

Refer to the original schematic for the illustrated connection paths.
